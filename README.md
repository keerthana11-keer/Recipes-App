## 📌 About The Project

**The Food Recipe** is an interactive recipe website developed as a front-end project to strengthen my skills in HTML, CSS, and JavaScript.

The website provides a collection of recipes with complete details such as ingredients, cooking instructions, category, rating, cooking time, difficulty level, and images.

This project focuses on creating a user-friendly experience without using any frameworks or backend technologies.

---

## ✨ Features

### 👨‍🍳 Recipe Management
- 56+ recipes with detailed information
- Recipe categories
- Ratings
- Cooking time
- Difficulty levels
- Ingredients and instructions
- Recipe images

### ⭐ User Features
- Add recipes to favorites
- Create shopping lists
- Give reviews and ratings
- User signup and login
- Share your own recipes with uploaded images

### 📊 Admin Dashboard
A separate admin dashboard is included with:

- Total users count
- Recipe statistics
- Reviews management
- Favorites tracking
- Shopping items data
- User table
- Activity logs
- Data export option

## 💾 Data Storage

This project uses **browser localStorage** for storing data.

The application stores:
- User details
- Favorites
- Shopping list items
- Reviews
- Shared recipes

No external database or backend server is used.

## ⚠️ Limitations

This project is created for learning and demonstration purposes.

Current limitations:

- Login and signup are demo features only
- Authentication is not real security
- Admin role is stored in localStorage
- Data is available only in the user's browser
- Multiple users cannot share the same database
